What is this experiment measuring?

We sample one query and eight keys with independent standard-normal components. Each bar is the softmax probability of a query–key dot product. Scaling divides each dot product by the square root of vector size. Normalized entropy measures how spread out the probabilities are: 0 means concentrated on one key, 1 means uniform.

This is a seeded numerical illustration using untrained vectors. It does not train a Transformer, measure gradients, or establish translation quality. Changing vector size regenerates vectors with the same seed; the scaled and unscaled panels always use the exact same vectors.
